# ⏳ Countdown Timer

A simple and interactive **Countdown Timer** built using **HTML, CSS, and JavaScript**.

## ✨ Features

* ⏰ Displays days, hours, minutes, and seconds
* 🔄 Updates the countdown in real time
* 🎯 Counts down to a specified date and time
* 📱 Simple and responsive user interface
* 🛑 Automatically stops when the countdown reaches zero

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🚀 How to Use

1. Open the project in your browser.
2. Set the desired target date and time.
3. The timer will automatically start counting down.
4. When the countdown reaches zero, the timer stops.
